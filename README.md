# 🧠 Treinando uma IA de Aprendizagem com NotebookLM

Este repositório contém o projeto prático desenvolvido durante o Bootcamp da Accenture na DIO, focado em explorar o potencial do Google NotebookLM como uma ferramenta de aprendizagem ativa e curadoria de conhecimento.

## 🎯 Contexto e Objetivos
O objetivo deste projeto foi utilizar o NotebookLM para centralizar fontes de dados sobre Inteligência Artificial Agêntica e extrair insights estruturados, criando um caderno temático inteligente para consultas futuras.

## 📚 Curadoria de Fontes
Foram utilizadas as seguintes fontes de dados em texto para alimentar a IA:
1. Documentação oficial de LLMs e Engenharia de Prompts.
2. Artigos sobre arquitetura de Agentes Autônomos de IA.
3. Casos de uso práticos de automação de dados com Python.

## 🛠️ Engenharia de Prompts e Aprendizados
Durante a interação com o NotebookLM, estruturamos comandos focados em síntese e extração de glossários técnicos. 
- **Desafio encontrado:** Ajustar o tom da resposta para termos técnicos em português sem perder a precisão conceitual.
- **Solução:** Aplicação de prompts com exemplos prévios (Few-shot prompting) para guiar o comportamento da ferramenta.

## 📝 Miniguia de Estudo Gerado
- **Conceito-Chave:** IA Agêntica difere de LLMs comuns por possuir autonomia para executar fluxos de tarefas em loops, utilizando ferramentas externas (APIs).
- **Prompt Reutilizável:** *"A partir dos documentos fornecidos, crie um resumo executivo em tópicos destacando as 3 principais restrições técnicas da arquitetura apresentada."*
